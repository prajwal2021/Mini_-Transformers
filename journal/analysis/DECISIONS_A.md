# Analysis-stream decisions (A-D###)

- A-D001 **Estimator: logistic GEE with fact clusters, not a mixed model, for the confirmatory tests.** `BinomialBayesMixedGLM` is variational Bayes: its posterior SDs are too small and it gives no frequentist p-values, so it cannot back a Holm family. GEE (Binomial/logit, exchangeable working correlation, groups = fact_id) gives robust CIs and p-values and handles the correlation from facts x seeds x variants x regimes. Cost: coefficients are population-averaged (smaller than conditional ones), and crossed template variance is not modelled as a random effect. The VB mixed logit (fact + fact-by-seed intercepts) is kept as a point-estimate sensitivity fit.
- A-D002 **Bias-reduced (Mancl-DeRouen) covariance with t(G-p) critical values.** With about 120 clusters the plain sandwich is anticonservative; the corrected version gave null rejection rates of 0.033-0.062 per test over 1000 replicates (E-A002).
- A-D003 **Seed is a fixed nuisance factor, not a random effect.** DESIGN.md writes (1|seed), but 3 seeds cannot estimate a variance. Seed shifts are absorbed by C(seed); seed-by-fact dependence by the fact clusters.
- A-D004 **Primary analysis at the final checkpoint only.** Rows across checkpoints are strongly dependent; pooling them would overstate precision. Earlier checkpoints feed learning curves and acquisition steps only. "Final" = largest checkpoint present in all seeds.
- A-D005 **Coding.** freq_c in {-1,0,+1} (one unit = a tripling, since bins are about 5/15/45 docs), div_c and regime_c = +-0.5. Full factorial, so main effects are averaged effects; family tests are freq_c, div_c, freq_c:div_c, regime_c.
- A-D006 **Test family = four storage tests H1-H4 (as the A01 prompt lists them); extraction tests form a second family.** This relabels DESIGN.md (where H3/H4 are extraction and H2 is diversity-by-frame). Diversity-by-regime is exploratory pending a team decision. Flagged in PREREG.
- A-D007 **Validation compares to the population-averaged truth.** Planted coefficients are conditional on random effects; the GEE targets the marginal value (smaller). Truth is computed by an independence-logit fit on a 18,000-fact simulation. Both columns are reported.
- A-D008 **Simulator: `regime` and `prompt_variant`.** `regime` is the iid/novel probe wording (the prompt's "iid-vs-novel"); `prompt_variant` = v1..v3 shared across regimes. The contract has no canonical/novel "frame" column; if the probe stream distinguishes it, the contract needs a column (open).
- A-D009 **docs/PREREG.md rewritten in place as draft v1** (the A01 prompt names it; v0 is in git history). Not frozen.
- A-D010 **tests/conftest.py added** so tests import this worktree's `src/` ahead of the editable install that points at the main checkout; also registers the `slow` marker (pyproject.toml untouched).
- A-D011 **PREREG follows DESIGN.md labels exactly (supersedes A-D006).** H1 storage rises with log exposure; H2 diversity x frame; H3 E2 gain after SFT bounded by storage; H4 gain larger for paraphrased facts. DESIGN states no correction; Holm over H1-H4 comes from PREREG v0 and is kept (flagged for confirmation).
- A-D012 **`probe_frame` (canonical/novel) replaces `regime`; the probe table has no regime column.** Contract aligned to the eval stream's EVAL_COLUMNS.md (adds split, attribute_id, true_logprob, baseline_logprob; checkpoint may be `init` = step 0; prompt_variant nested in frame; val rows never analysed; binding_score = true - baseline checked). Document-level regime is used by no DESIGN hypothesis.
- A-D013 **H2 is tested by the div_c:frame_c interaction (predicted +).** The "templated better only on canonical" clause is judged descriptively from simple-effect CIs. Template effects are within-frame fixed dummies (a full set is collinear with frame_c; the canonical frame has one test variant).
- A-D014 **H3/H4 use the fact as the unit, E2 only, with majority rules** (stored if > half of seeds; correct if > half of seeds x items), so Fisher and McNemar (as DESIGN writes them) see independent facts. Item-level tests would pseudo-replicate (3 seeds x 3 questions per fact). Cost: the 2-shot base is near the floor at fact level, which inflates the H3a gain. H3 = intersection-union of McNemar (base vs SFT) and Fisher (stored x correct), p = max.
- A-D015 **H4 between-condition test = stratified permutation test on per-fact gains** (DESIGN names only Fisher/McNemar). Per-condition McNemar and 2x2 tables are reported with it.
- A-D016 **QA table contract** (fact_id, seed, eval_set E0/E1/E2, question_id, model base_0shot/base_2shot/sft, exact_match, stored_pretrain, freq_bin, div_bin, sft_split) with checks that E0/E1 are SFT-train facts, E2 held-out, disjoint. Aliases subset/correct accepted. Meaning of E0/E1/E2 matches the eval stream's mock qa_test.jsonl (E2 = 60 facts x 3 templates).
- A-D017 **Comparator = base_2shot** (same prompt format as SFT); base_0shot is simulated and reported. PLACEHOLDER to confirm before the freeze.
- A-D018 **Equivalence margins are placeholders:** OR 1.25 (+-0.223 log-odds) for H1/H2 as the prompt says, and +-0.10 risk difference for H3/H4 (my placeholder, not given). "No meaningful effect" only if the whole CI lies inside.
- A-D019 **Exposure coding:** freq_c = log3(train_mentions) centred when that column exists, else the bin code. Recorded in PREREG; the switch happens before the freeze.
- A-D020 **H4 is confirmatory but underpowered (Holm power 0.36 at 60 E2 facts; 0.64 at 90).** Options for the architect are in PREREG section 12. Not silently downgraded.
- A-D021 **Validation estimands.** H1/H2 recovery is judged against the population-averaged truth (large simulation, same estimator); H3/H4 against the same estimators on 9000 facts. H3/H4 bootstrap CIs under-cover (0.88-0.92) and the H3/H4 tests are conservative under the null (0.00-0.02); both are stated in the validation report.- A-D022 **PREREG v3 applies the architect's decisions.** H1, H2, H3 confirmatory with Holm m = 3; H4 pre-registered secondary (effect and CI only, no significance claim). Logged as deviation D1 (and D2-D5) in PREREG section 0 for the DESIGN v1.3 fold-in. The H4 power in the prompt (0.36) is now 0.33 after the 3-probe change (A-D023).
- A-D023 **Fact-level rule: "more than half" at both levels.** Stored = stored on >= 2 of 3 test probes within a seed, then in a majority of seeds; QA-correct = >= 2 of 3 E2 phrasings per seed, then majority of seeds. `any` and `all` are sensitivity rules (`aggregation.py`). The simulator now has 3 test probes per fact (1 canonical + 2 novel) to match; the eval stream documents `test-canon`, `test-n1..3`, so the count needs confirming.
- A-D024 **Comparator base_2shot; base_0shot is secondary** (sensitivity row).
- A-D025 **One checkpoint = the final checkpoint of each seed** (after a fixed epoch count chosen on validation loss). `prepare_primary` selects each seed's own final checkpoint and warns if they differ. This replaces DESIGN's val-probe selection rule (PREREG D4).
- A-D026 **Realized diversity covariate** `rdiv_z` = z-score of 1 - mean_pairwise_jaccard over facts. The file is not yet in the main checkout, so the schema is mine (assumed column meanings listed in ANALYSIS_INPUT section 3; confirm with the bank stream). It is a sensitivity analysis (replace div_bin, or add to it), converted to the nominal contrast with the realized gap. A weak manipulation attenuates nominal H2 toward zero (validation: 0.80 -> 0.49 -> 0.25 at strengths 1.0 / 0.6 / 0.3; realized estimate stays about 0.78).
- A-D027 **Simulator extensions** that keep earlier random streams unchanged when the feature is off: measured `train_mentions` (optional log-normal noise driving storage), `manipulation_strength` (latent realized diversity), `stored_tokennorm` (8% flips), simulated `realized_diversity.csv`.
- A-D028 **Sensitivity suite** (`run_sensitivity.py` -> reports/tables/sensitivity.md + .csv): aggregation any/majority/all, exposure bins vs log3 mentions, with/without template terms, GEE vs Bayesian mixed point estimate, `stored_tokennorm`, base_0shot comparator, realized diversity (replace/both), complete-separation report. Rows that cannot run are listed as skipped, not dropped. Separation handling: detection of all-0/all-1 design cells; fallback ladder primary -> independence -> no covariates -> non-informative (p = 1); a fit with |coef| or SE above 8 counts as failed.
- A-D029 **Report builder.** Template with `{{macros}}`; a lint fails the build on any number typed in the template (names such as H1, E2, base_2shot are exempt); `numbers.json` records the source file of every number. Backends: headless Chrome/Edge (6 pages here), else a Matplotlib layout (5 pages). Pandoc/LaTeX and weasyprint were not implemented: none is installed, and an untested path is not trustworthy. Page gate 5-7 pages from the PDF page tree. The SIMULATED banner (page header, watermark, every figure) is on by default and off only with `--real`; `--simulate --real` is refused. Simulated builds go to docs/report/simulated/ and are committed so they can be reviewed.
