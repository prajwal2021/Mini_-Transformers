# Decisions (eval stream)

- E-D001 **Scorer contract:** `Scorer.score(prompt, continuation) -> float` is the total (summed) natural-log probability of the continuation; the harness sees no tokens. `MockScorer` = lookup table + noise that is a pure hash of (seed, prompt, continuation), so it does not depend on call order.
- E-D002 **Stored (DESIGN 6, PREREG):** rank 1 among the 6 same-attribute values AND binding score > 0, where binding = log p(v | correct entity) - mean log p(v | the 5 other entities of the same attribute), same template with only the entity swapped. Both terms and the baseline are logged (`true_logprob`, `baseline_logprob`).
- E-D003 **Ties count against the fact:** rank = 1 + number of other candidates scoring >= the true value, so a tie for first is rank 2 and not stored. `n_ties` is logged.
- E-D004 **Continuation format:** prompts never end in whitespace; the continuation is " " + value (byte-level BPE puts the space on the value token).
- E-D005 **Regimes and frames:** DESIGN has no "iid/novel" probe regime; the iid/novel split exists for val/test documents (D-024). Probe `regime` = wording distance from the training frames: iid = declarative templates in the train register (plus the canonical prefix), novel = structurally different wording. `frame` = canonical (canonical-sentence prefix) or novel (any template), as in H2. 5 templates per regime are assigned by a seeded shuffle to val (2) and test (3), disjoint, fixed.
- E-D006 **Length-normalised ranking:** DESIGN asks for summed and length-normalised log-probs; the Scorer cannot expose token counts, so normalisation is per character of the continuation (`rank_charnorm`). `stored` uses summed scores only.
- E-D007 **Mock oracle:** additive model score(e, v_o) = prior[o] + bind[o, prompt] * [e owns v_o], which fixes rank, binding and stored analytically for exact-recovery tests.
- E-D008 **SFT split source:** `scripts/build_sft_mock.py` defaults to the `sft_split` already recorded in kb.json (8/2/10 per cell, identical in shape to a stratified build) so E2 stays consistent with the KB; `--split-source seeded` builds a new seeded split stratified by freq_bin x div_bin.
- E-D009 **SFT templates:** 20 attributes x 4 hand-written base forms x 3 wrappers = 12 phrasings (7 train / 2 val / 3 test). Test includes a base form (B4) never seen in train or val; answers are the KB canonical sentence. Rows carry prompt and completion separately for answer-only loss.
- E-D010 **probe_frame rename (E02):** the probe-side `regime`/`frame` columns are replaced by `probe_frame` (canonical, novel). `regime` now means only the document-level iid/novel regime (`doc_loss_by_regime`). Supersedes the probe part of E-D005. Documented in docs/EVAL_COLUMNS.md.
- E-D011 **Group scoring:** the six entities of one attribute under one prompt variant are scored as a 6 x 6 matrix S[i][j] = score(prompt_i, value_j) (36 calls, cached by (prompt, continuation)). Real binding baseline and the permutation null both read this matrix, so no extra model calls are needed for the null.
- E-D012 **Permutation null:** for the row of entity i, each other entity's value o is taken as pseudo-truth: rank of S[i][o] in row i, binding S[i][o] - mean over k != i of S[k][o], stored = rank 1 and binding > 0. `null_stored_rate` = mean over the 5 pseudo-truths (row level). Identical procedure to the real one (E-D002/E-D003). Aggregates: `chance_report`, `fact_level`, `checkpoint_summary`.
- E-D013 **Untrained model:** checkpoint id `init` (INIT_CHECKPOINT) is the epoch-0 model; `--include-init` calls the scorer factory with "init" and the mock gives it a value prior with no entity binding.
- E-D014 **Probe wording:** replaces the E-D005 template pools. Per attribute 1 hand-written canonical prefix (tested equal to the KB canonical_prefix for all 120 facts) and 3 hand-written novel prefixes (src/slm/eval/wording.py, audit in reports/tables/probe_wording.md). DESIGN wants 2 val + 3 test templates but only 4 prompts exist per attribute, so: val = canonical + 1 novel, test = canonical + 2 novel; the novel templates are disjoint between val and test (seeded choice), the canonical prefix is shared. 5 probes per fact (600 items per checkpoint and seed).
- E-D015 **Length normalisation:** optional `score_detailed(prompt, continuation) -> (logprob, n_tokens)`; the harness uses it when present (`norm_unit = token`) and otherwise falls back to the continuation length in characters (`char`). `rank_tokennorm` and `stored_tokennorm` are a secondary sensitivity outcome; `stored` always uses summed scores. Replaces `rank_charnorm` (E-D006).
- E-D016 **Document loss:** `doc_loss_by_regime(nll_fn, docs)` is token-weighted (total NLL / total tokens) per split x regime, and per author_role, tone and held_out_style. DESIGN.md defines no role/tone cells; the held-out roles and tone come from D-024.
- E-D017 **Overlap CLI:** `scripts/check_probe_overlap.py --split-manifest` checks every fact's novel prompt + value against the train files (8-grams of lowercased words). No manifest format exists yet, so it accepts `{"train": [...]}`, `{"train_files": [...]}` or `{"splits": {"train": {"files": [...]}}}`; .jsonl files use the "text" field. Canonical prompts are reported but do not fail.
- E-D018 **Hypothesis map gaps:** docs/HYPOTHESIS_MAP.md. The probe table cannot test H1/H2 (no exposure column) or H3/H4 (no fact-level stored, no QA table). Proposed: train_mentions, epochs_seen, exposure, value_len_tokens, entity_mentions, stored_fact (rule to be pre-registered).
