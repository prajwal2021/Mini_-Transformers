=== 5. DOCUMENT VALIDATOR: src/slm/data/doc_validator.py ===
validate_doc(text, plan_row, kb, pools) -> (ok, reasons[]). Checks:
 V1 Each assigned fact's value appears EXACTLY once (word-boundary match); templated: canonical
    sentence appears verbatim once; paraphrased: canonical sentence and canonical_prefix absent.
 V2 Binding: entity name appears within 25 words of the value (same sentence preferred).
 V3 No other measured fact's value string and no other measured digit run appears.
 V4 No digit run of length >=2 other than assigned values; no year; no numeric dates; spelled
    numbers >= ten (ten..ninety, hundred, thousand, dozen) forbidden.
 V5 Capitalized-token whitelist (heuristic, ignore sentence-initial words and a small allowed
    set: months, weekdays, greetings, sign-offs): entity names, core-fact tokens, filler names
    for this doc, assigned person/place/role values. Anything else is flagged (log); more than 2
    flags rejects.
 V6 No Q/A markers (Q:, A:, Question, Answer), at most 2 sentences ending with "?".
 V7 No markdown (#, **, backticks, leading bullets "- " or "* "), no meta words (AI, assistant,
    fictional, invented, synthetic, dataset, study, corpus, "as requested", "here is").
 V8 Word count within the doc's range (+/- 15%) and under the 330-word cap.
 V9 English-only (reject if >2% non-ASCII characters).
Return structured reasons so the generator can give feedback on retry.
