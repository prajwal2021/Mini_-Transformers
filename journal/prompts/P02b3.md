 A. Attempt table (per model): doc_id | mode(s) | doc_type | attempt | accepted? | rule ids failed.
 B. V1 sub-causes with counts per model: value missing; value present more than once; templated
    sentence missing or altered (show the nearest matching sentence by character similarity);
    canonical sentence leaked in a paraphrased doc; canonical prefix leaked. For each sub-cause show
    3 examples: assigned value, expected text, and what the document actually contained (the
    sentence). Also count how often the value appears in another form (spelled out, hyphenated, with

 C. V2: for failed attempts, the entity string and value, the sentence containing the value, its word
    count, and whether the entity appears elsewhere in that sentence in a different form (plural,
    pronoun, alias). Distribution of word distance between entity and value.
 D. V5: the 25 most frequent flagged capitalized tokens per model, each tagged by where it occurs
    (heading/title line, sign-off, body sentence, chat label). Count docs with Title Case headings and
    docs with a lowercase title line.
 E. V6: 3 examples from mini of what triggered it (question count, Q/A markers).
 F. V8: histogram of actual/target words in bins (<0.6, 0.6-0.8, 0.8-1.2, 1.2-1.4, >1.4), by model and
    by doc type; mean ratio by doc type.
 G. Retry dynamics: pass rate by attempt number (1, 2, 3); for attempts 2 and 3, the share of docs
    where each prior failing rule was fixed, persisted, or replaced by a new rule.
 H. Tokens and cost: reasoning vs visible output tokens per call (mean, by model); hypothetical cost
    for the full 2407-doc run if reasoning tokens were zero and visible output unchanged, at observed
    attempts per doc; same recomputed at a hypothetical 70% first-attempt pass rate (attempts per
    doc = 1.43). Label clearly as hypothetical.
 I. Six rejected attempts printed IN FULL (3 nano, 3 mini) chosen to illustrate the three most
    frequent failure types, each with its doc_id, assigned facts + modes, rules failed and reasons.
 J. Coverage gap: which doc types or modes ended with zero accepted docs for each model, with their
    attempt histories.
