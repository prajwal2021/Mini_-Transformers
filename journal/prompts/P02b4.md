STAGE 1 - offline only (no API calls)

1.3 V2 rewrite (E2). Bound = exists an occurrence of the entity within 25 words of the value (word distance between them, not sentence length), same sentence, no newline between. Entity matching is case-insensitive for common-noun entities and case-exact for proper-name entities (ships, org; derive from kb.json capitalisation if there is no flag). Add V2b mis-binding guard: for the assigned value, no other KB entity of the same family that appears in the document may be as close or closer to the value than the assigned entity. Report the word-distance distribution in the replay.
1.4 V5 redefinition (E3). Purpose: stop invented proper names/titles that could collide with KB values or create unlabelled extra facts. Do not count: sentence-initial words, "I"/"I'm", the title line (first non-empty line, <=14 words, no terminal punctuation), chat speaker labels, sign-off lines, "Subject:" lines, any token that is part of an assigned value, KB entity names, org/department terms, plan-assigned incidental names (travellers, pets), style-card role titles, filler-pool names. Count remaining capitalised tokens not at sentence start; fail if more than 2, and print each flagged token with its sentence.
1.5 V6 (E4). Q/A marker = line-initial or inline "Q:", "A:", "Question:", "Answer:" labels only (regex anchored). Remove any bare-word match on "answer". Keep "more than 2 question sentences fails".
1.6 V8 (E5). Accept words in [0.7*target, min(1.3*target, 360)], floor 60. Record that 360 words is about 486 tokens at 1.35 tokens/word, which fits the 512 context; P03 must report the share of docs over 512 tokens.
1.7 V13 casing. Every occurrence (case-insensitive) of "Aurelia Skyways", "Companion Animal Travel Desk", "CATD" and every proper-name KB entity must be exactly canonical-cased. A title line may not be all-lowercase or all-caps.
1.8 V15 attribute fidelity (E7). Create configs/attribute_cues.yaml for all 20 attributes with: meaning (short plain phrase used in the prompt), cue_any (3-8 lowercase stems that a sentence stating this attribute should contain, including synonyms so paraphrases stay diverse), derived from the 20 canonical sentence patterns. For every PARAPHRASED fact: the sentence that holds the value must contain at least one cue_any stem and no hedge word (may, might, could, usually, typically, generally, approximately, roughly, sometimes, often, normally, or "around" directly before the value). Templated facts already carry the canonical sentence. Do not add a negation rule ("must not exceed" is legitimate); contradictions are for the P02d judge audit.

STAGE 2 - prompt v3 and pilot rerun
2.1 prompt_templates/v3.txt (keep v2 for provenance). Requirements:
- Plain text only, ASCII punctuation, no markdown, no preface or afterword, no sign-off on chat threads, no title on chat threads/emails. "Write Aurelia Skyways and Companion Animal Travel Desk exactly with these capitals."
- Length given as an explicit range: between 0.8*N and min(1.2*N, 340) words (target N); validator band is wider on purpose.
- Per assigned fact list: entity (exact string), value (exact string), meaning phrase from attribute_cues.yaml, mode.
  - templated: include this exact sentence once, verbatim, as its own sentence (no connector before it, no case change; in chat threads it may follow a speaker label).
  - paraphrased: one new sentence in your own words that contains the exact entity, states the meaning in plain words, contains the exact value, keeps entity and value within 12 words in the same sentence, with no hedging words and no reuse of the canonical wording.
  - both: the value appears exactly once in the whole document; never repeat, recap, summarise or restate it (including in replies, closing lines or headings).
- Doc-type edits (type ids unchanged so plan.jsonl is unchanged): "complaint letter + reply" becomes ONE reply from the Desk to a traveller's complaint, summarising the complaint in one sentence with no numbers, no separate letter; chat thread: speaker-label lines only. Adapt other types minimally.
