# Analysis validation on simulated data

Generated by `scripts/validate_analysis.py` (all seeds fixed; simulated data only, no real result). Model: logistic GEE, fact clusters, exchangeable working correlation, bias-reduced covariance, t(G-p) intervals; Holm across H1-H4 (alpha = 0.05).

## Simulation settings

- Planned size: 20 facts per cell x 6 cells = 120 facts; 3 seeds; 3 prompt variants; 2 regimes (2160 rows at the final checkpoint).
- Planted log-odds (conditional): freq 0.9, diversity 0.7, freq x diversity -0.4, regime (novel - iid) -0.8; intercept -0.3.
- Random-effect SDs: fact 0.8, seed 0.2, fact x seed 0.8, fact x regime 0.3, prompt variant 0.15.
- The planted coefficients are conditional on the random effects. The GEE estimates population-averaged coefficients, which are smaller in magnitude; the 'population-averaged truth' column is that target, obtained from an independence-logit fit on a simulation with 18000 facts. Recovery is judged against it.
- Replicates: 500 per planted-effect scenario, 1000 for the null. Non-converged fits in the planned scenario: 0.
