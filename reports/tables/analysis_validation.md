# Analysis validation on simulated data (A02)

Generated by `scripts/validate_analysis.py` (all seeds fixed; simulated data only, no real result). H1/H2: logistic GEE with fact clusters (bias-reduced covariance, t(G-p)); H3/H4: DESIGN's Fisher exact and McNemar tests on facts (plus a stratified permutation test for the between-condition H4 contrast). Holm across H1-H4 at alpha 0.05; "power" counts a rejection only when the effect has the predicted sign.

## Simulation settings

- Planned size: 20 facts per freq x div cell x 6 = 120 facts; 3 seeds; test probes per fact x seed: 1 canonical + 3 novel; SFT fact split 40/10/50 (E2 = 10 facts per cell = 60 facts); 3 questions per fact and eval set.
- Planted probe log-odds (conditional): freq 0.9, diversity 0.3, frame (novel - canonical) -0.5, diversity x frame 1.0, freq x diversity -0.4; intercept -0.3. Templated novel-frame penalty -1.0, paraphrased 0.0.
- Planted QA logits: base_2shot -3.0 + 1.0*stored; sft -1.5 + 2.2*stored + 0.6*div_c (E2).
- Random-effect SDs (probe): fact 0.8, seed 0.2, fact x seed 0.8, fact x frame 0.3, template 0.15; (QA) fact 0.7, fact x seed 0.5.
- Planted H1/H2 coefficients are conditional on the random effects, while the GEE targets population-averaged values (smaller in magnitude). Recovery is judged against the population truth, computed with the same estimator on a very large simulation (18000 facts for H1/H2, 9000 for the extraction estimands). The H3/H4 estimands are risk differences of the fact-level (majority) outcomes.
- Replicates: 400 per planted-effect scenario, 500 per null scenario. Non-converged GEE fits in the planned scenario: 0.

## How to read these numbers

- Power is conditional on the planted effects, which are assumptions, not predictions; treat it as a sensitivity analysis (what size of effect the design can detect), not as a forecast.
- H1/H2 (GEE) hold the nominal false-positive rate (null A and B, per-test column 'rejection_raw'). The H3/H4 tests are valid but conservative: their null rejection rates are below 0.05 because the fact-level outcomes are sparse and discrete (few discordant or non-zero-gain facts). The reported H3/H4 power is for these conservative tests. The family-wise raw rate in null A is therefore below the 1 - 0.95^4 = 0.185 of four exact tests.
- H3 power is high partly because the majority rule leaves the 2-shot base near the floor at fact level (a fact is base-correct only if most of its items are), which makes the gain large; a different aggregation changes the estimand and the power.
- Bootstrap CIs for H3/H4 (60 facts, percentile) under-cover somewhat (see the ci_coverage columns); treat them as approximate.
